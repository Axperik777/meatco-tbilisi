# MeatCO
Статический сайт доставки мяса. Версии: грузинская (по умолчанию), русская, английская.
Контакт: +995 568 258 118.
Районы: Ваке, Сабуртало, Диди Дигоми; соседние адреса по согласованию.

## Файлы
- dist/index.html — структура, стартовая грузинская разметка.
- dist/style.css — адаптивное оформление и локальные шрифты.
- dist/app.js — 94 переводимых строк на язык, переключение и сохранение языка, подготовка WhatsApp-сообщения, валидация необязательного веса.
- dist/config.js — контакт и выключенный по умолчанию аналитический мост.
- dist/assets — локальные изображения и шрифты.
- serve.mjs — локальный предпросмотр на 127.0.0.1:4178.
- .openai/hosting.json — существующий проект Sites, не создавать повторно.

## Поведение
Прямые CTA открывают WhatsApp. Карточки категорий открывают необязательную форму с категорией, весом, районом, комментарием и интересом к дополнительным продуктам.
Перед отправкой доступен текст сообщения. Нажатие кнопки не подтверждает заказ и не отправляет сообщение автоматически.
Язык задаётся ?lang=ka|ru|en, затем сохранённым выбором, затем конфигурацией. Все метаданные, ошибки, alt и сообщения локализованы. Пользовательский комментарий не переводится автоматически.
Форма сохраняется только в памяти открытой страницы. Язык — localStorage, UTM/click ID — sessionStorage. Нет сторонних аналитических загрузок.
Мост dataLayer включается только при config.analytics.enabled=true и, по умолчанию, наличии согласия. Он не заменяет настроенный GTM/Pixel/GA4/CAPI и не считает клики покупками.

## Подтверждение содержания
Не публикуются придуманные цены, сроки доставки, скидки, отзывы, происхождение мяса или способы оплаты.
Три иллюстративных изображения сгенерированы для дизайна и помечены как иллюстрации. Точные позиции и прайс ещё не переданы пользователем.
Грузинские тексты технически проверены; перед запуском рекламы рекомендована редактура носителем.
Публичное открытие текущего частного проекта не выполнялось.
