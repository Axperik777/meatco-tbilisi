# MeatCO
Сайт доставки свинины и говядины по Тбилиси: грузинский, русский и английский.
Публичный сайт: https://axperik777.github.io/meatco-tbilisi/
Контакт WhatsApp: +995 568 258 118. Ваке, Сабуртало, Диди Дигоми; соседние адреса — после проверки.

## Сценарий заказа
Прямые CTA открывают WhatsApp. Категории и части мяса открывают необязательную форму.
Подбор по блюду переносит вид мяса, блюдо и число человек. Овощи, фрукты, яйца отмечаются отдельно и включаются в текст запроса.
Вес, район и комментарий необязательны. Полная сумма и условия согласуются с менеджером до подтверждения.
B2B-раздел использует отдельный текст для ресторанов и кафе.
Кнопка открывает подготовленный текст: сообщение и заказ автоматически не отправляются.

## Локали и данные
173 строки на каждый язык. Приоритет: ?lang=ka|ru|en → сохранённый выбор → грузинский.
Метаданные, кнопки, форма, ошибки, подсказки, alt и WhatsApp-сообщения локализованы.
Пользовательский комментарий не переводится. Форма живёт только в памяти страницы.
Язык сохраняется в localStorage, UTM/click ID — в sessionStorage.
Аналитика выключена. В dist/config.js есть условный мост dataLayer; он не заменяет Pixel, CAPI, GA4 или GTM.
Событие перехода в WhatsApp не означает покупку.

## Разработка
Минимальный статический стек: HTML, CSS, JavaScript без зависимостей.
- node serve.mjs — http://127.0.0.1:4178/
- node validate.mjs — синтаксис, ключи локалей, локальные ресурсы, якоря и ID.
- dist/ — публикуемая папка.
- .github/workflows/pages.yml — проверка и GitHub Pages при push в main.
- .openai/hosting.json — сохранённая конфигурация предыдущего проекта Sites.

## Что требует фактических данных
Цены, точные SKU, происхождение и температурный режим мяса, график, тарифы доставки и способы оплаты не выдуманы.
Фото созданы для иллюстрации; это не фотографии фактических товаров или готовых блюд на продажу.
Тексты отредактированы на трёх языках; внешняя проверка носителем грузинского не проводилась.
Работу каталога WhatsApp Business, оплату и реальную доставку нельзя проверить по исходникам сайта.
